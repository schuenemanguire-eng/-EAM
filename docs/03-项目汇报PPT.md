## 03 · 项目背景

**为什么需要这套系统？**

- 中小企业人事管理依赖人工，员工档案、考勤、请假、薪资分散低效
- 请假审批线下流转，审批人不明确、进度不可控
- 薪资核算人工易错，缺乏全局经营数据视角

**项目目标**

- 实现人事核心流程线上化、自动化
- 数据统一管理，业务可追溯
- 轻量单机部署，开箱即用

## 04 · 系统功能概览

- **登录认证**：4 种角色（admin / hr / supervisor / employee），Token 鉴权
- **数据看板**：员工、部门、待审批、今日考勤等核心指标一屏总览
- **组织架构**：部门树、职位（P1-P8）管理
- **员工管理**：档案增删改查、搜索筛选、离职办理
- **考勤管理**：上下班打卡，自动判定迟到/早退/缺卡
- **请假管理**：在线申请，单级审批，实时通知
- **薪资管理**：工资项录入，实发自动计算

---

## 05 · 技术架构

**后端**：Java 17 · Spring Boot 2.7 · MyBatis-Plus · Sa-Token · WebSocket · Knife4j

**前端**：Vue 3 · Vite 6 · Ant Design Vue 4 · Pinia · TypeScript

**数据库**：MySQL 8.0 · InnoDB · utf8mb4

**架构风格**：前后端分离 + 简化 DDD 分层

- 领域层纯业务实体，不依赖框架
- 仓储接口定义于领域层，实现在基础设施层
- 无外键设计，逻辑删除，业务层校验关联

---

## 06 · 数据库设计

**9 张业务表**：dept / position / employee / sys_user / attendance_rule / attendance_record / leave_application / salary / attendance_monthly_stat

**设计要点**

- 无外键，关联在业务层校验
- 逻辑删除（deleted 字段），核心数据不物理删除
- 关键唯一索引保障数据一致性：
  - 工号唯一
  - 打卡 (employee_id, date) 唯一
  - 薪资 (employee_id, year, month) 唯一

## 07 · 关键流程演示：请假审批

```
员工提交请假
   ├─ 自动计算请假天数
   ├─ 自动指派审批人（部门主管）
   ▼
审批人收到 WebSocket 通知
   ├─ 查询待审批列表
   ├─ 批准 / 拒绝
   ▼
状态更新，实时通知申请人
```

**单级审批 · 自动指派 · 全程可追溯**

## 09 · 质量保障：问题修复

| 类别 | 典型问题 | 修复 |
|------|----------|------|
| 框架兼容 | WebSocket Bean 冲突 / Knife4j javax-jakarta | 修正注册方式与依赖版本 |
