企业员工管理系统 操作手册

本手册介绍系统如何安装、登录以及各功能模块的使用方法，适用于管理员、人事、部门主管与普通员工。

1. 系统访问

1.1 访问地址

入口 地址
前端页面 http://localhost:3000
后端接口文档 http://localhost:8080/doc.html

1.2 登录

  1. 打开浏览器访问前端地址，进入登录页。
  2. 输入用户名与密码（默认密码均为 123456）。
  3. 点击「登录」进入系统，登录成功后跳转数据看板。

不同角色登录后功能权限一致，但业务操作范围不同（详见各章节说明）。

1.3 测试账号

账号 角色 适用场景
admin 系统管理员 全功能操作
wang_zg 人事 员工、薪资、考勤管理
li_jl 研发部主管 审批请假
liu_gc 普通员工 打卡、请假申请

2. 数据看板

登录后默认进入「数据看板」，一屏展示核心指标：

  • 员工总数 / 在职员工数 / 本月新入职
  • 部门数量
  • 待审批请假数量
  • 今日打卡人数 / 今日迟到人数

用途：管理层快速掌握人事运营概况。

3. 部门管理

入口：左侧菜单 → 部门管理

  • 查看：以树形展示总公司与子部门。
  • 新增：点击「新增部门」，填写部门名称、父部门、排序、状态，点击确定。
  • 编辑：点击行内「编辑」修改部门信息，可设置部门主管。
  • 删除：点击行内「删除」并确认（逻辑删除，不物理移除数据）。

4. 职位管理

入口：左侧菜单 → 职位管理

  • 查看：职位列表（职位名称、所属部门、职级）。
  • 新增：点击「新增职位」，填写职位名称、所属部门、职级（P1–P8）。
  • 编辑 / 删除：对应行内操作按钮。

5. 员工管理

入口：左侧菜单 → 员工管理

  • 查看：员工列表，支持按姓名/工号搜索、按部门筛选。
  • 新增：点击「新增员工」，填写姓名、工号（必填且唯一）、部门、职位、入职日期、联系方式等，点击确定。
  • 编辑：修改员工档案信息。
  • 离职：点击「离职」办理离职，员工状态变为「离职」。
  • 删除：点击「删除」并确认（逻辑删除）。

工号已存在时系统会提示，需更换工号后重试。

6. 考勤管理

入口：左侧菜单 → 考勤管理

6.1 打卡

  1. 进入考勤页面，点击「上班打卡」。
  2. 下班时点击「下班打卡」。
  3. 系统按考勤规则自动判定状态：正常 / 迟到 / 早退 / 缺卡。

6.2 记录查询

  • 选择员工、起止日期查询考勤记录。
  • 同一员工同一天仅一条记录，下班打卡自动补录到当日记录。

7. 请假管理

入口：左侧菜单 → 请假管理

7.1 员工提交申请

  1. 切换至「申请请假」。
  2. 选择请假类型（年假 / 病假 / 事假 / 婚假）。
  3. 选择开始、结束时间，填写请假原因。
  4. 点击提交，系统自动计算请假天数，并自动指派部门主管为审批人。

7.2 主管审批

  1. 以部门主管账号登录，进入请假管理。
  2. 切换至「待我审批」列表。
  3. 查看申请详情后点击「批准」或「拒绝」。

7.3 进度查看

  • 员工可在「我的请假」查看申请状态（待审批 / 已批准 / 已拒绝）与审批时间。

8. 薪资管理

入口：左侧菜单 → 薪资管理

  1. 选择年份、月份查看薪资列表。
  2. 点击「新增薪资」，选择员工，填写基本工资、奖金、津贴、扣款。
  3. 系统自动计算实发工资，点击保存。
  4. 可对已有记录进行编辑。

同一员工同年月仅允许一条薪资记录，重复录入会被拦截。

9. 个人操作

  • 退出登录：右上角用户名下拉菜单 → 退出登录。
  • 接口文档：开发人员可访问 http://localhost:8080/doc.html 在线调试接口。

10. 常见问题（FAQ）

Q1：登录提示“用户名或密码错误”？

确认账号存在且密码为 123456；若数据库曾重置，需重新执行初始化脚本。

Q2：新增员工提示“工号不能为空”？

工号为必填项，请手动填写唯一工号（如 EMP011）。

Q3：打卡后看不到记录？

刷新页面并在考勤记录中按日期查询；同一天重复打卡只会更新当日记录。

Q4：提交请假后一直“待审批”？

请用对应部门主管账号登录，在「待我审批」中处理；审批完成后状态自动更新。
