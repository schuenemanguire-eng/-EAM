Project Overview · 项目介绍

企业员工管理系统（EAM）项目介绍

一个面向中小企业人事管理场景的 Web 应用系统，覆盖员工信息管理、考勤打卡、请假审批、薪资管理、数据看板等核心人事业务，支持本地单机部署。

后端Java 17 · Spring Boot 2.7 前端Vue 3 · Vite 6 数据库MySQL 8.0 部署本地单机

项目名称

企业员工管理系统（Enterprise Employee Management System，简称 EAM）

一个面向中小企业人事管理场景的 Web 应用系统，覆盖员工信息管理、考勤打卡、请假审批、薪资管理、数据看板等核心人事业务，支持本地单机部署。

业务场景

中小企业在日常人事管理中存在以下典型痛点：

员工信息分散

员工档案、组织架构、职位信息缺乏统一管理，查找与维护困难。

考勤依赖人工

上下班打卡靠纸质或口头记录，迟到、早退、缺卡无法自动判定。

请假流程冗长

请假申请线下流转，审批人指派不明确，进度无法跟踪。

薪资核算繁琐

基本工资、奖金、津贴、扣款分散记录，实发金额人工计算易出错。

缺乏全局视角

管理层无法快速掌握员工总数、部门构成、待审批事项等经营数据。

EAM 系统针对上述问题，将人事管理核心流程线上化、规范化、自动化，帮助中小企业在不引入重型系统的前提下，快速建立数字化人事管理能力。

核心功能

1. 登录与身份认证

  • 基于 Sa-Token 的无状态 Token 认证，登录后获得 Bearer Token。
  • 内置四种角色：admin（系统管理员）、hr（人事）、supervisor（部门主管）、employee（普通员工）。
  • 除登录、接口文档等白名单路径外，所有接口均需登录后访问。

2. 数据看板

  • 一屏汇总核心指标：员工总数、在职员工数、本月新入职、部门数量、待审批请假、今日打卡人数、今日迟到人数。

3. 组织架构管理

  • 部门管理：树形结构（根部门 + 子部门），支持新增、编辑、删除，可设置部门主管（manager_id）。
  • 职位管理：职位名称、所属部门、职级（P1–P8），支持增删改。

4. 员工管理

  • 员工档案增删改查，字段含姓名、工号（唯一）、部门、职位、入职日期、手机、邮箱、性别、出生日期。
  • 支持按姓名/工号搜索、按部门筛选。
  • 支持离职办理（状态流转）与删除（逻辑删除）。

5. 考勤管理

  • 上下班打卡（clock_in / clock_out），同一天同一员工仅一条记录。
  • 依据考勤规则（上班/下班时间、迟到/早退阈值）自动判定状态（正常/迟到/早退/缺卡）。
  • 支持按员工、日期区间查询考勤记录。

6. 请假管理

  • 员工提交请假申请（年假/病假/事假/婚假），系统自动计算请假天数。
  • 单级审批：自动将部门主管设为审批人（approver_id），主管可批准或拒绝。
  • 审批结果通过 WebSocket 实时通知申请人。

7. 薪资管理

  • 按员工 + 年月录入基本工资、奖金、津贴、扣款，系统自动计算实发工资。
  • 唯一约束保证同一员工同年月仅一条薪资记录，防止重复录入。

案例特点

架构设计

  • 简化 DDD 分层：api（接口层）→ application（应用编排）→ domain（领域层）→ infrastructure（基础设施层）。
  • 领域层纯净：domain 实体为纯业务实体，不依赖 MyBatis/MySQL；仓储接口定义在 domain，实现在 infrastructure。
  • 无外键设计：数据库不建外键，关联校验全部在业务层完成，逻辑删除保证核心业务数据不物理删除。

技术栈

端 技术栈
后端Java 17、Spring Boot 2.7、MyBatis-Plus 3.5、Sa-Token、WebSocket、Knife4j（OpenAPI3）
前端Vue 3、Vite 6、Ant Design Vue 4、Pinia、TypeScript、Axios
数据库MySQL 8.0、InnoDB、utf8mb4

工程化亮点

  • 零第三方运行时依赖：本地单机运行，不引入 Redis、消息队列、云存储等组件，开箱即用。
  • 单页自包含交付：文档、接口文档（Knife4j）开箱即用，前后端分离部署。
  • 代码结构清晰：按 DDD 分包，实体/仓储/服务职责明确，便于维护与扩展。
  • 统一响应与异常处理：全局统一 Result 包装、全局异常拦截，接口返回格式稳定。

数据设计

  • 9 张业务表：部门、职位、员工、用户、考勤规则、打卡记录、请假申请、薪资、月度考勤统计。
  • 关键唯一索引：工号唯一、打卡（employee_id, date）唯一、薪资（employee_id, year, month）唯一。
  • 初始化内置：管理员 admin（密码 123456）、4 个部门、8 个职位、10 名员工及对应账号，便于演示与验收。

运行环境

  • JDK 17+、Maven 3.9+、Node.js 20+、MySQL 8.0。
  • 后端默认端口 8080，前端开发服务器默认端口 3000，接口文档 http://localhost:8080/doc.html。
